# GitSU v0.24 — Единна операция / Vollständiger Vorgang

Единствен Repository Workspace: избор на репозитори → избор на операция → преглед → изрично потвърждение → изпълнение → повторна проверка. Няма необходимост от преминаване през отделни менюта GitHub, Sync, Operations и Rules. / Ein Repository auswählen, Vorgang wählen, prüfen, bestätigen, ausführen und nachprüfen — alles an einem Ort.

Операции / Vorgänge: Inspect, Push, Update, GitHub origin, File Copy, Git rules. За промени се изисква потвърждение / Änderungen benötigen Bestätigung. Потребителските данни не се превеждат.

Стартиране / Start: gui.pyw (Windows с Python 3). Node/Electron може да се изтегля при първото стартиране. Няма EXE инсталатор. / Kein EXE-Installer.

Статус: Release Candidate. Не са проверени Windows/NAS/GitHub E2E тестове. / Windows/NAS/GitHub-E2E-Tests stehen aus.
