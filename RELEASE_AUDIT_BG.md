# GitSU v0.29 — квалификационен отчет

- Добавено: GitHub CLI browser/device login и read-only auth status.
- GitSU не приема GitHub пароли или PAT; gh управлява удостоверяването.
- Изисква инсталиран `gh` в PATH и браузър.
- Поправен `npm run check`: премахната препратка към несъществуващ тест, добавени проверки на новия код.
- Подменено JPG лого с PNG с прозрачност.
- Остават: Windows/Electron GUI E2E, NAS тестове, HACS runtime validation, безопасен transactional copy/rollback.
- Това е RC, не окончателен Enterprise release.
