# GitSU v0.32 — динамичен работен панел

- Изборът на операция сменя етикетите на бутоните и контекстното обяснение на BG/DE.
- Изпълнението и предварителната проверка показват активен spinner, неопределен прогрес и реално изминало време.
- При последващата проверка се показва отделна фаза.
- Не се показва измислен процент: Git subprocess не предоставя достоверен прогрес чрез текущия IPC интерфейс.
- Смяната на операция по време на активна задача е блокирана.
- При приключване или грешка индикаторът се премахва.

## Ограничения
Текущата версия **не** предоставя поток от Git stdout/stderr, процент на реално прехвърлените байтове или бутон за безопасно прекъсване. Това изисква допълнителен IPC progress протокол и backend промени. Не е извършен реален Windows/NAS end-to-end тест. Release Candidate, не окончателен Enterprise release.
