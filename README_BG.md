# GitSU SUPERUSER Enterprise Pro — Български

**Разработено и представено от PasevSU-DEV** · https://pasevsu.github.io/

## Стартиране (v0.43.4)

Най-лесно: `release\GitSU-win-x64-0.43.4.zip` → разархивирайте → `GitSU.exe` (без инсталация). От сорс: `cd data\app && npm i && npm start`.

### Панели
Преглед · Промени (diff, stage, commit) · Операции · Синхронизация (watcher + lease) · История · Настройки.

### Свързване на папка с репозитори
„Добави“ отваря един диалог: избирате папка, репозитори и действие — регистриране, клониране, свързване (папка без git към remote, без да се пипат файловете), създаване или публикуване.

### Windows ↔ Home Assistant
Пакетите `gitsu-watcher-windows-0.42.0.zip` и `gitsu-watcher-ha-0.42.0.tar.gz` пазят единствен писач чрез lease (`refs/gitsu/lease/<клон>`); другият възел следва с ff-only. Нужни са синхронизирани часовници (NTP). Windows автостарт: `pwsh install-task.ps1`. Проверка на файловете: `SHA256SUMS.txt`.

## Старо стартиране (Python)

Разархивирайте пакета. Стартирайте `gui.pyw` за графичен режим без конзола, `gui.py` за Python режим или `gui.cmd` за конзолно стартиране. Не е необходим инсталатор на GitSU, но е необходим Python 3 с tkinter. При първо стартиране може да е необходим интернет за Node.js и Electron.

## Езици

В горната лента изберете **Български** или **Deutsch**. Изборът се запазва локално. Интерфейсът включва преводи на навигацията, показателите, бутоните, статусите, филтрите, действията и помощните описания. Непреведените технически идентификатори и оригиналните диагностични съобщения се запазват, за да не се загуби точността им.

## Основни възможности

- Регистрация, проверка и наблюдение на локални Git репозитории.
- Проверка на клон, локални промени и GitHub origin.
- Преглед и потвърждение преди Git операции.
- План за копиране преди файловата синхронизация.
- Контролер на ресурси, журнал на операции и системна диагностика.

## Данни и поверителност

Приложението работи локално. Работните данни и кешовете се намират в `data/`. Git и GitHub мрежовите операции се изпълняват само при съответните действия. Първоначалното изтегляне на зависимости изисква мрежова връзка.

## Ограничения

Това е Release Candidate. Реалното стартиране под Windows, NAS и GitHub сценарии не е напълно квалифицирано. Не изпълнявайте операции с единствено копие на важни данни без резервно копие.


## Локално обновяване на репозитори между папки
Изберете изходното репозитори в GitSU → „Локално обновяване · папка → папка“ → въведете целева папка → „Провери“ → прегледайте списъка → „Изпълни“. Програмата копира нови и променени файлове, пропуска `.git` и символните връзки и сравнява отново изходната и целевата папка. Не изтрива допълнителни файлове в целта и не пренася Git историята. При презаписване няма гарантиран rollback — направете резервно копие на целевата папка.
