# ChronoSeal v89 — миграционен кандидат (НЕ Е РЕЛИЙЗ)

Извършена е първа ограничена миграционна партида: ширината на Legal/QR колоната и четири padding стойности се зареждат от семантичния JS регистър `95_semantic_migration.js`. Не са променяни криптографски алгоритми.

## Три редундантни метода

1. `atomic`: нова staging директория, проверка на хешове, атомарно преименуване; отказ при съществуваща цел.
2. `overlay`: архивиране на цялата цел, прилагане на файловете, SHA-256 проверка и rollback при грешка.
3. `patch`: изисква инсталиран Git и съвместим patch; проверява с `git apply --check`, архивира, прилага и връща backup при грешка. Не изисква и не създава `.git` метаданни. Ако Git липсва, използвайте `atomic` за нова цел или `overlay` за съществуваща папка.

**Важно:** тези методи са алтернативни механизми за прилагане, а не три независими реализации на PDF оформлението. Прилагане само върху копие/проверена база.

Остава: пълен инвентар, миграция на всички останали правила, визуална квалификация на четирите профила, криптографска end-to-end квалификация и clean-extract release gate.
