# Enterprise qualification gate — DEV v31

Тази версия запазва работещите генератори, криптографския мост, loaders и стиловете.

Поправена е критична слабост във finalization: връщане на PASS от verifier вече не е достатъчно за VERIFIED. Изисква се записан JSON audit с PASS, съвпадащ SHA-256 на PDF и поне два проверени времеви печата.

Това е структурен контрол, НЕ независимо доказателство за криптографска валидност на два TSA токена. Production release остава BLOCKED до реално E2E генериране, TSA, PKI/OCSP/CRL, DSS и визуално сравнение на четирите профила.

Не променяйте pdf-rfc3161 dist/index.js и не изключвайте защитния scanner.
