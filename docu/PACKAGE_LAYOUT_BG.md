# ChronoSeal — един GUI и централна документация

- Единствен GUI entrypoint: `ChronoSeal_GUI.pyw`.
- Стартиране: `Start_ChronoSeal.bat`.
- Помощни UI класове са `.py` модули, а не самостоятелни `.pyw` прозорци.
- Документация: само `docu/`.
- Изключени от дистрибуцията: лични примерни PDF документи, предишни отчети, логове и генерирани доказателства.
- Този пакет е интеграционен кандидат; не представлява доказана съдебна квалификация.
- Важна бележка: OCR, TSA, PDF и всички режими изискват Windows end-to-end квалификация преди release.
